# Project Rules

- Do not use Unicode `U+2014` em-dash characters or their HTML named entity anywhere in source code, comments, benchmarks, or documentation.
- Avoid dramatic historical hooks, legacy-cost cliches, instructional conditional openers, parenthetical taxonomy headers, and rigid two-sentence paragraph templates.
- Mix short declarative sentences with longer technical explanations.
- Use `buf` (`buf lint`, `buf format`, `buf generate`, `buf build`) for all Protobuf schema linting, C++20 code generation, and binary `FileDescriptorSet` builds.
